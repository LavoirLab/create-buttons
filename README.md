# Create Buttons WebApp

Interactive Telegram WebApp for visually designing and generating inline keyboards for Telegram bots.

## Features
- **Visual Button Grid**: Add rows and buttons with a few taps.
- **Support for Multiple Types**: Link (URL), Share link, Copy text.
- **Custom Styling**: Background colors (Primary Blue, Emerald Green, Sunset Orange, Dark Slate, Transparent).
- **Telegram Native SDK**: Seamless integration with Telegram WebApp theme and `Telegram.WebApp.sendData`.
- **Vercel Ready**: Preconfigured with `vercel.json` for 1-click deployment.

## Deployment on Vercel
1. Import this repository into Vercel.
2. Framework Preset: **Other** / Static.
3. Root Directory: `./` (root).
4. Click **Deploy**.
